# Capas originales

Las capas vectoriales usadas en la ejecución están en el equipo de Gabriela, en
`C:\Users\Gabriela_Jerez\Desktop\distancias_mineria`. No se adjuntaron a esta sesión.
Este repositorio contiene código, configuración, documentación y resultados, pero
no los shapefiles ni sus archivos auxiliares.

El inventario `resultados/inventario_capas.csv` identifica las fuentes, subcapas,
CRS y cantidades de geometrías. Para reproducir el cálculo se necesitan el shapefile
minero completo (.shp, .shx, .dbf, .prj y archivos auxiliares pertinentes) y las 11
carpetas temáticas originales, conservando los nombres usados en config.json.
Los nombres de las carpetas se detallan en la configuración.

Esta carpeta está excluida por defecto de Git salvo este README. Si se decide versionar
capas, revisar su licencia y tamaño y ajustar .gitignore deliberadamente. No existe
un enlace de descarga verificado de estas fuentes en este repositorio.
